# 🏰 Shivrajya Cinematic

> An immersive, cinematic scroll-based historical experience celebrating
> **Chhatrapati Shivaji Maharaj** and the journey of **Swarajya**.

## 🌐 Live Website

**[Visit Shivrajya Cinematic
→](https://shivrajya-cinematic-nine.vercel.app/)**

## 📖 About the Project

**Shivrajya Cinematic** is a premium interactive historical web
experience designed to present the life, vision, forts, battles, Mavlas,
Swarajya expansion, and Rajyabhishek of **Chhatrapati Shivaji Maharaj**
through a cinematic digital journey.

Instead of presenting history as a traditional static website, the
project combines storytelling, animations, interactive sections,
atmospheric visuals, sound controls, maps, timelines, and scroll-based
interactions to create an experience that feels like an interactive
historical film.

## 🎞️ Story Journey

The website is structured as a continuous historical journey:

**उदय → जिजाऊ व संकल्प → गड-किल्ले → स्वराज्याचा विस्तार → रणभूमी व गनिमी कावा →
मावळे व स्वराज्य → राज्याभिषेक → अंतिम वारसा**

The experience gradually moves from the Sahyadri landscape and the early
vision of Swarajya toward forts, military strategy, Mavla bravery, the
expansion of Swarajya and finally the grand Rajyabhishek of Chhatrapati
Shivaji Maharaj.

## ⚔️ Historical Sections

### मातृत्व व संस्कार

The story of Rajmata Jijau and the values, vision and inspiration that
shaped young Shivaji Maharaj.

### गड-किल्ले

An interactive exploration of forts and their importance in the Swarajya
network.

### स्वराज्याचा विस्तार

A visual representation of the growth and geographical spread of
Swarajya.

### रणसंग्राम, गनिमी कावा आणि आरमार

A dedicated section covering military strategy, guerrilla warfare, fort
networks and the Maratha navy.

### मावळे व स्वराज्य

A tribute to the Mavlas and important personalities who dedicated
themselves to Swarajya.

### राज्याभिषेक

The cinematic climax depicting the historic Rajyabhishek of Chhatrapati
Shivaji Maharaj.

### अंतिम वारसा

The journey concludes with the enduring legacy of Swarajya and the
message:

> **जय भवानी! जय शिवाजी!**

## 🚀 Run Locally

Clone the repository:

``` bash
git clone https://github.com/rohanshinde8080/shivrajya-cinematic.git
cd shivrajya-cinematic
```

Install dependencies:

``` bash
npm install
```

Start the development server:

``` bash
npm run dev
```

Then open the local URL shown by Vite in your browser.

## 📦 Production Build

``` bash
npm run build
```

To preview the production build:

``` bash
npm run preview
```

## 🎨 Design Direction

The visual language is inspired by the atmosphere of **Swarajya and the
Sahyadri**:

-   Deep black and earthy brown backgrounds
-   Saffron/orange highlights
-   Royal gold accents
-   Warm cinematic lighting
-   Fort and mountain silhouettes
-   Atmospheric particles and fog
-   Historical Marathi typography
-   Scroll-driven transitions
-   Minimal but premium UI controls

## 🎯 Project Goal

The goal of this project is to demonstrate how modern frontend
technologies can be used to transform historical storytelling into an
**interactive, immersive and emotionally engaging digital experience**.

It combines:

**History + Storytelling + UI/UX + Animation + Frontend Engineering**
